ISYARA — Sumber materi dan perangkat lunak

Referensi alfabet dan contoh titik tangan
Samuel Ady Sanjaya (2024), BISINDO Indonesian Sign Language: Alphabet Image Data, Mendeley Data v1.
https://doi.org/10.17632/ywnjpbcz8m.1 — CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)
Titik tangan dari foto dataset dinormalisasi dan dipakai sebagai referensi pencocokan (alphabet.json) serta melatih model alfabet satu tangan dan dua tangan. Sumber tidak menyatakan dukungan terhadap ISYARA.

Model alfabet tumpang tindih (M, N, Y)
Dilatih dari jarak antartitik tangan pada dataset Samuel Ady Sanjaya (CC BY 4.0) dan BISINDO Hand-Sign Detection Dataset, Rhio Sutoyo (MIT):
https://github.com/rhiosutoyo/Indonesian-Sign-Language-BISINDO-Hand-Sign-Detection-Dataset

Ilustrasi tangan 3D (alfabet-3d/)
Dirender ulang untuk ISYARA dari titik tangan dataset Samuel Ady Sanjaya (CC BY 4.0). D-kontak-v2 dan J-kelingking digambar ulang berdasarkan pose pada D5.jpg dan J4.jpg dari dataset yang sama.

Kosakata gerak (gerak/, kosakata-gerak.json, model-kosakata.json)
sigawari, WL-BISINDO-10class, https://huggingface.co/datasets/sigawari/wl-bisindo-10class — CC BY-NC 4.0 (https://creativecommons.org/licenses/by-nc/4.0/). Animasi 3D dirender dari landmark tangan dataset. Model ExtraTrees dilatih dari 240 contoh tiga penutur. Untuk penggunaan nonkomersial.

Pelacakan tangan dan wajah
Google MediaPipe Tasks Vision, model hand_landmarker dan face_landmarker. https://github.com/google-ai-edge/mediapipe (Apache 2.0)
Runtime dan model diunduh dari cdn.jsdelivr.net dan storage.googleapis.com, dengan salinan identik di wasm/ dan models/ sebagai cadangan.

Ringkasan dan latihan pintar
Google Gemini API, dipanggil dari server dengan data progres tanpa nama dan tanpa gambar.

Antarmuka
React (MIT), Lucide (ISC), Hono (MIT), GSAP (lisensi standar GreenSock, gratis), font Atkinson Hyperlegible Next (OFL) dan Bricolage Grotesque (OFL) melalui Fontsource. Background potongan kertas dibuat untuk ISYARA dengan model gambar AI. Lisensi tambahan di direktori licenses.
